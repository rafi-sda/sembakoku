Pengaturan Data & Sinkronisasi

Status Data Saat Ini

Secara default, data tersimpan di browser (Memory) agar Anda bisa langsung mencoba aplikasi. Untuk menyimpan data ke Google Spreadsheet secara permanen, ikuti panduan di bawah.

1. Siapkan Google Apps Script

Buat Google Spreadsheet baru. Klik menu Ekstensi > Apps Script. Hapus semua kode di sana, lalu copy-paste kode di bawah ini, dan klik Deploy (Terapkan) > New Deployment (Penerapan Baru) sebagai "Web App" (Aplikasi Web). Akses: Anyone (Siapa saja).

2. Masukkan URL Web App (Google Apps Script)

Setelah di-deploy, Google akan memberikan sebuah URL. Masukkan URL tersebut ke kolom di bawah ini untuk mengaktifkan sinkronisasi otomatis.
